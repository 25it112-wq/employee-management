# Employee Time Management System

A frontend demonstration built with HTML, CSS, vanilla JavaScript and localStorage.

## Run
- Open `index.html` in a browser (double-click), or
- In VS Code, install the "Live Server" extension, right-click `index.html` and choose "Open with Live Server".

## Notes
- Data is stored only in this browser (localStorage).
- No login, no backend, not secure and not suitable for payroll.
- Use "Load demo data" on the Dashboard to try it with fictional employees.
